# ru2en

> System-wide russian to english translator for macOS. Select text, hit `Cmd+C` twice, the selection is replaced by a native-sounding english translation in under a second. Formatting is preserved byte for byte. Built on Hammerspoon and the xAI API.

Выделяешь русский текст, жмёшь `Cmd+C` дважды подряд — выделение заменяется английским переводом меньше чем за секунду. Форматирование сохраняется побайтово: отступы, пустые строки, дефисы, регистр.

Работает в любом приложении: Telegram, браузер, Cursor, Slack, нативные приложения macOS.

## Установка

Нужен ключ [xAI API](https://console.x.ai) и Homebrew.

```sh
git clone https://github.com/Argona7/ru2en.git
cd ru2en && ./install.sh
```

Скрипт поставит Hammerspoon, спросит ключ и положит его в Keychain, пропишет загрузчик и включит автозапуск. Останется одно ручное действие — выдать Hammerspoon разрешение Accessibility в System Settings и перезапустить его.

## Хоткеи

| Комбинация | Что делает |
| --- | --- |
| `Cmd+C` `Cmd+C` | перевести выделенное на английский и вставить поверх |
| `Cmd+Shift+R` | показать русский перевод выделенного в панели для чтения |
| `Option+Cmd+T` | перевод на английский для текста без кириллицы (сам скопирует выделение) |
| `Option+Cmd+Z` | вернуть последний оригинал на место перевода |

Обычный одиночный `Cmd+C` не затронут. Если в скопированном тексте нет кириллицы, двойное нажатие молча ничего не делает — просто копирование.

## Панель чтения

`Cmd+Shift+R` на выделенном английском тексте открывает панель с русским переводом рядом с самим текстом — справа, если до края экрана хватает места, иначе слева. Внизу кнопка «Скопировать». Закрывается по Esc, по клику мимо или по крестику.

Панель не забирает фокус: приложение, в котором ты читаешь, остаётся активным. Буфер обмена тоже не страдает — выделение снимается через `Cmd+C`, но прежнее содержимое буфера возвращается на место со всеми форматами, включая картинки и RTF.

Панель можно таскать за полоску в шапке и растягивать за уголок внизу справа. Заданный руками размер запоминается до перезапуска Hammerspoon; вернуть автоподбор высоты — `require("ru2en.window").resetSize()`.

Текст в панели выделяется мышью. Как только что-то выделено, кнопка сама меняет подпись на «Скопировать выделенное» и копирует именно выделенный кусок, а не весь перевод.

Наведение на кнопки пришлось реализовать вручную. Неактивирующее окно не получает от системы событий движения мыши, поэтому CSS `:hover` в нём не срабатывает никогда. Модуль забирает у страницы координаты кнопок через `getBoundingClientRect`, сам ловит движения курсора и переключает класс `.hover`. JS дёргается только на входе и выходе из кнопки, а не на каждое движение.

### Куда она встаёт

Координаты выделения берутся через Accessibility (`AXBoundsForRange`). В нативных приложениях и Safari это точный прямоугольник текста, и панель встаёт вплотную сбоку от него.

Браузеры на Chromium и Electron-приложения этих координат не отдают. Тогда панель прижимается к дальнему краю экрана — к правому, если текст в левой половине, и наоборот. Позиция курсора для этого не годится: он стоит посреди только что выделенного текста, и панель легла бы прямо на него.

Высота подгоняется под объём текста и упирается в 62% высоты экрана, дальше текст скроллится. Ширина 540 точек — это около 60 символов в строке, то есть та длина, на которой проза перестаёт утомлять.

`Cmd+Shift+R` в браузерах — это жёсткая перезагрузка страницы. Глобальный хоткей перехватывает событие раньше браузера, так что hard reload там работать перестанет. Комбинация меняется в `ru2en/config.lua`.

## Модель

`grok-4.20-0309-non-reasoning` через xAI API. Замеры на одном тексте:

| Вариант | Время |
| --- | --- |
| grok-4.20-0309-non-reasoning | 1.3с |
| grok-4.3 | 8.1с |
| grok-4.5 | 13.0с |
| grok-4.6 | 28.6с |
| cursor-agent + grok-4.6-low-fast | 21.4с |

Reasoning-модели и агентские обёртки тут не нужны: перевод короткого текста — задача без размышлений, и весь выигрыш даёт non-reasoning модель плюс переиспользование HTTP-соединения внутри процесса Hammerspoon.

## Файлы

- `ru2en/init.lua` — eventtap на двойной `Cmd+C`, вставка перевода, точка входа
- `ru2en/api.lua` — общий клиент xAI: ключ из Keychain, запрос, таймаут, кэш
- `ru2en/cache.lua` — кэш переводов в памяти
- `ru2en/selection.lua` — клавиши и буфер: снятие выделения с возвратом буфера, привязка хоткеев по аппаратным кодам
- `ru2en/reader.lua` — панель чтения EN→RU: выделение, язык, координаты, запрос
- `ru2en/window.lua` — сама панель на `hs.webview`: вёрстка, автовысота, копирование
- `ru2en/guards.lua` — детерминированная починка форматирования, чистый Lua без `hs.*`
- `ru2en/config.lua` — модель, окно двойного нажатия, лимиты, таймаут, хоткеи, настройки панели
- `ru2en/prompt.txt` — системный промпт RU→EN
- `ru2en/prompt.reader.txt` — системный промпт EN→RU для чтения
- `tests/test_guards.lua` — тесты на guards
- `hammerspoon-init.lua` — шаблон загрузчика, `install.sh` подставляет в него путь и кладёт в `~/.hammerspoon/init.lua`
- `install.sh` — установка с нуля, безопасно запускать повторно

Правки любого `.lua` или `prompt.txt` перезагружают Hammerspoon автоматически.

## Гарантии форматирования

Промпт просит модель держать форматирование, но полагаться на это нельзя, поэтому поверх ответа идут детерминированные правки в `guards.lua`:

1. Срезается обёртка из тройных бэктиков и кавычек вокруг всего ответа — но только если в оригинале их не было.
2. Выдуманные моделью пустые строки удаляются. Модель любит «проветрить» плотное сообщение лишним переносом; удаляются только те пустые строки, которым нет соответствия в оригинале, и только если после этого число строк совпадёт точно.
3. При совпадении числа строк построчно возвращаются ведущие пробелы и табы из оригинала.
4. Длинное тире и короткое тире заменяются на дефис, кавычки-ёлочки на прямые — только если пользователь сам их не печатал.
5. Знак валюты переносится вперёд числа: `150$` становится `$150`, `200$$$` становится `$200`, а `$80$` (модель поставила знак с обеих сторон) становится `$80`. Применяется всегда, потому что по-английски знак после числа не пишут никогда.
6. Регистр первой буквы строки приводится к оригиналу, список и нумерация при этом пропускаются.
7. Местоимение `I` понижается до `i`, если исходная строка целиком в нижнем регистре. Имена собственные (`India`, `Moscow`) не затрагиваются.
8. Ведущие и завершающие переводы строк приводятся к оригиналу.

Если модель вернула другое число строк, правила про отступы и регистр отключаются, а пунктуационные продолжают работать.

## Тесты

```sh
lua tests/test_guards.lua
```

`guards.lua` не зависит от Hammerspoon, поэтому тесты гоняются обычным интерпретатором (`brew install lua`).

## Промпт

Заточен под один сценарий: переписка с рекламодателями в личке X и реплаи под твитами. Отсюда сокращения (`tbh`, `idk`, `imo`, `rn`, `btw`, `lmk`, `ngl`, `lmao`, `gonna`, `wanna`), твиттерный словарь (квоут → `qrt`, репост → `rt`, лс → `dms`, закреп → `pinned post`, тз → `brief`) и починка того, что выдаёт неносителя — прежде всего `20$` → `$20`.

Голый список сокращений модель игнорирует: он был в промпте, а `tbh` и `idk` не появлялись ни разу. Работают только явные пары «честно говоря → tbh», поэтому словарь оформлен таблицей соответствий. По той же причине примеры надо писать ровно в желаемом виде: строка «зайдет → will land» научила модель говорить `will` вместо `gonna` по всему тексту.

Отдельным правилом стоит запрет что-либо выбрасывать. Без него модель молча удаляла незнакомые слова: «йо броски давай делать квот» превращалось в `yo let's do some qrts`, где обращение исчезло, а единственное число стало множественным.

Правила форматирования стоят в начале файла блоком «hard rules». Это не косметика: когда они лежали после словаря сокращений, модель начинала вставлять лишнюю пустую строку в каждое второе сообщение.

Подбирать формулировки на глаз бессмысленно, для этого есть A/B-стенд — он гоняет два промпта по восьми реальным текстам параллельно и печатает результаты рядом:

```sh
python3 tests/compare_prompts.py ru2en/prompt.txt ru2en/prompt.candidate.txt
```

## Настройка

Промпт — `ru2en/prompt.txt`, правится на лету без перезапуска.

Модель, окно двойного нажатия (по умолчанию 400мс), лимит длины (8000 символов) и таймаут (8с) — в `ru2en/config.lua`.

## Кэш

Повторный перевод того же текста отдаётся из памяти мгновенно, без обращения к сети: 0.000с против 1.4с на первом запросе. Живёт час, ключ включает модель и промпт, так что разные направления перевода не смешиваются. Правка любого файла перезагружает Hammerspoon и очищает кэш — изменённый промпт не может продолжать отдавать старый перевод.

Время жизни — `cache_ttl_s` в конфиге. Сбросить вручную: `require("ru2en.api").cache.clear()`.

## Ключ API

Лежит в Keychain под сервисом `ru2en-xai`, Hammerspoon предавторизован на чтение. Обновить:

```sh
security add-generic-password -U -s ru2en-xai -a "$USER" \
  -T /usr/bin/security -T /Applications/Hammerspoon.app -w "$XAI_API_KEY"
```

## Если не работает

Состояние всех частей одной командой в консоли Hammerspoon:

```lua
require("ru2en").doctor()
```

Проверить задержку и ответ API:

```lua
require("ru2en").benchmark()
```

Прогнать живую проверку форматирования на восьми формах текста:

```lua
dofile(require("ru2en").root .. "/tests/live_check.lua")
```

Проверить промпт панели чтения на пяти типах английского текста:

```lua
dofile(require("ru2en").root .. "/tests/live_reader.lua")
```

Проверить сам жест в черновике TextEdit (сам откроет окно, напечатает, нажмёт два раза и сверит результат):

```lua
dofile(require("ru2en").root .. "/tests/app_check.lua")
```

Тест отказывается печатать, если фокус ушёл в другое приложение, поэтому во время прогона не переключайся.

## Разрешение Accessibility

Если `doctor` показывает `accessibility: false` сразу после того, как ты включил тумблер — macOS записала разрешение, но Hammerspoon читает его только при старте. Перезапусти:

```sh
killall Hammerspoon; sleep 2; open -a Hammerspoon
```

Двойной `Cmd+C` не срабатывает — Hammerspoon потерял разрешение Accessibility. System Settings → Privacy & Security → Accessibility.

Вставка не происходит, но перевод сделан — поле не принимает `Cmd+V`; перевод остался в буфере, вставится вручную.
